# Product — 生活選物店後端

## 這是什麼

「生活選物店」的後端 API：提供會員、商品、購物車三大功能，供獨立部署的前端 `hexschool-store-frontend` 串接。商品以家居、文具、小物為主。

本專案同時是 2026 企業專題班的單人專題，需獨立部署至雲端並通過審核。

## 為誰而做

| 使用者 | 需求 |
| --- | --- |
| 一般訪客（未登入） | 瀏覽商品列表與單品，依分類篩選、關鍵字搜尋、分頁；被引導註冊或登入 |
| 一般會員 | 註冊、登入，管理自己的購物車（加入、調整數量、移除、查看） |
| 管理員 | 透過 API 新增、編輯、刪除商品（不提供後台頁面） |
| 課程審核者 | 以 Postman／Swagger 直接測試 API，閱讀 README 與 OpenAPI 文件，使用測試帳號與 seed 資料驗證 |

## 目標

1. **通過審核達標**：總分 ≥ 70 且後端 ≥ 24 分，於 2026/11/24 23:59 前繳交。
2. **完整展示核心流程**：註冊登入 → 瀏覽搜尋分頁 → 購物車操作，且購物車與後端資料一致。
3. **練習 spec-driven development**：先有 `specs/constitution.md` 與 `specs/product.md`，每個功能一份 `specs/NNN-feature/spec.md` 並通過 Constitution Check，commit 紀錄能看出開發過程。
4. **可獨立測試與部署**：公開 API Base URL、`/api-docs` 互動式文件、seed 測試資料，2026/11/13 至 2026/12/04 保持運作。

## 非目標（本期不做）

- 訂單、結帳與金流。
- 管理員後台頁面（僅提供商品管理 API）。
- 第三方登入與密碼重設，僅支援 email + 密碼與 JWT。
- Refresh token 與 token 撤銷：只發有效期 7 天的 access token，登出僅在前端清除 token。
- 庫存、優惠券、評價、商品多圖與推薦。
  - 因不做庫存，購物車單項數量以固定上限（如 99）限制；`constitution.md` T-3 的「超出庫存」於本期解讀為「超出此固定上限」。

## 成功標準

- 審核者只靠 README 與 `/api-docs` 就能呼叫每支 API。
- seed 資料足以展示分頁、分類與搜尋（至少 20 筆商品、3 個以上分類）。
- 一般會員無法以任何方式取得管理員權限。
- 購物車的重複加入、商品不存在、數量不合理等邊界情況皆有明確回應。
